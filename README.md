# Blackjack SOLID

Proyecto académico desarrollado en C# con el objetivo de aplicar principios de programación orientada a objetos y buenas prácticas de arquitectura de software mediante la creación de un juego de Blackjack.

## Descripción

Este proyecto simula el funcionamiento básico del juego Blackjack, donde un jugador compite contra la banca intentando obtener una puntuación cercana a 21 sin pasarse.

El desarrollo se enfocó en organizar el código de forma clara, separando responsabilidades y aplicando principios SOLID para facilitar el mantenimiento y la comprensión del proyecto.

## Objetivo del proyecto

Aplicar conceptos de arquitectura de software y programación orientada a objetos en un caso práctico, utilizando el juego Blackjack como ejemplo.

## Tecnologías utilizadas

* C#
* .NET
* Programación orientada a objetos
* Principios SOLID

## Funcionalidades principales

* Creación de cartas y baraja.
* Reparto de cartas al jugador y a la banca.
* Cálculo del puntaje de cada participante.
* Validación de reglas básicas del Blackjack.
* Comparación de resultados entre jugador y banca.
* Organización del código en clases con responsabilidades definidas.

## Principios aplicados

Durante el desarrollo se tuvieron en cuenta buenas prácticas como:

* Separación de responsabilidades.
* Código organizado por clases.
* Bajo acoplamiento entre componentes.
* Mayor facilidad para modificar o ampliar funcionalidades.
* Aplicación de principios SOLID en la estructura del proyecto.
